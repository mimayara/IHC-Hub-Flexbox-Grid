CSS Grid

Aprenda a organizar elementos em linhas e colunas.

← Voltar ao Hub

1. O que é CSS Grid?

CSS Grid é um sistema de layout que permite organizar elementos em linhas e colunas. Ele facilita a criação de páginas estruturadas, galerias de imagens, painéis e diferentes tipos de layouts.

Diferentemente do Flexbox, que trabalha principalmente em uma dimensão por vez, o Grid permite controlar linhas e colunas simultaneamente.

2. Como ativar o Grid?

Para utilizar o Grid, aplicamos a propriedade display: grid no elemento que contém os itens. 

.container {
    display: grid;
}

O elemento se torna um contêiner Grid, e seus elementos filhos diretos passam a ser itens da grade.

3. Criando colunas

A propriedade grid-template-columns define as colunas da grade. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 15px;
}

Nesse exemplo, criamos três colunas com a mesma proporção. A unidade fr representa uma fração do espaço disponível.

Usando repeat()

grid-template-columns: repeat(3, 1fr);

Essa forma abreviada também cria três colunas de mesma proporção.

4. Criando linhas

A propriedade grid-template-rows permite definir a altura das linhas da grade. 

.container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    grid-template-rows: 100px 150px;
    gap: 15px;
}

Nesse exemplo, a grade possui duas colunas e duas linhas, com alturas definidas de 100 e 150 pixels.

5. Espaçamento entre os itens

A propriedade gap define o espaço entre as linhas e as colunas. 

gap: 20px;
row-gap: 10px;
column-gap: 20px;

Podemos definir o mesmo espaçamento para todas as direções ou configurar separadamente linhas e colunas.

6. Ocupando várias colunas ou linhas

As propriedades grid-column e grid-row permitem que um item ocupe mais de uma coluna ou linha. 

.destaque {
    grid-column: span 2;
}

Nesse exemplo, o item com a classe destaque ocupa o espaço de duas colunas.

8. Quando utilizar CSS Grid?

  • Para criar layouts com linhas e colunas.
  • Para organizar galerias de imagens.
  • Para montar painéis e páginas com diferentes áreas.
  • Para estruturar o conteúdo de páginas web.
