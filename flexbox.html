CSS Flexbox

Aprenda a organizar e alinhar elementos com Flexbox.

1. O que é Flexbox?

Flexbox é um modelo de layout do CSS que facilita a organização, o alinhamento e a distribuição de elementos dentro de um contêiner. Ele é muito utilizado para criar menus, cartões e organizar conteúdos em diferentes tamanhos de tela.

2. Como ativar o Flexbox?

Para utilizar o Flexbox, aplicamos a propriedade display: flex no elemento que contém os itens. 

.container {
    display: flex;
}

O elemento que recebe essa propriedade passa a ser o contêiner flexível, e seus elementos filhos diretos tornam-se itens flexíveis.

3. Principais propriedades

flex-direction

Define a direção em que os itens serão organizados.

flex-direction: row;
flex-direction: column;

row: organiza os itens em uma linha.

column: organiza os itens em uma coluna.

justify-content

Distribui os itens ao longo do eixo principal.

justify-content: center;
justify-content: space-between;
justify-content: space-around;

align-items

Alinha os itens no eixo transversal do contêiner.

align-items: center;
align-items: flex-start;
align-items: flex-end;

flex-wrap

Permite que os itens passem para outra linha quando necessário.

flex-wrap: wrap;

gap

Define o espaço entre os itens.

gap: 20px;

flex-grow

Define quanto um item pode crescer para ocupar o espaço disponível.

.item {
    flex-grow: 1;
}

4. Exemplo prático

No exemplo abaixo, os cartões são organizados lado a lado, com espaçamento entre eles. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    flex-wrap: wrap;
    gap: 15px;
}

5. Quando utilizar Flexbox?

  • Para organizar menus de navegação.
  • Para alinhar botões e ícones.
  • Para centralizar elementos na página.
  • Para distribuir cartões e componentes em uma linha ou coluna.
